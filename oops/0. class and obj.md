# Java Classes and Objects (Complete Practical Guide)

## What is a Class?

A **class** is a blueprint or template for creating objects.

Think of it like a house plan.

* House plan = Class
* Actual house = Object

### Example

A student has:

* Name
* Roll Number
* Age

These are common for every student.

```java
class Student {
    String name;
    int rollNo;
    int age;
}
```

This is only a blueprint.

No student exists yet.

---

# What is an Object?

An object is a real instance of a class.

Creating an object:

```java
Student s1 = new Student();
```

Now Java allocates memory for `s1`.

---

# Creating Multiple Objects

```java
class Student {

    String name;
    int age;
}

public class Main {

    public static void main(String args[]) {

        Student s1 = new Student();
        Student s2 = new Student();

        s1.name = "Rahul";
        s1.age = 20;

        s2.name = "Priya";
        s2.age = 21;

        System.out.println(s1.name);
        System.out.println(s2.name);
    }
}
```

Output

```
Rahul
Priya
```

---

# Memory Representation

```
Stack

s1 ---------
            |
s2 -----    |
         |  |
         ↓  ↓

Heap

Object 1
---------
name = Rahul
age = 20

Object 2
---------
name = Priya
age = 21
```

Variables (`s1`, `s2`) are stored in the stack.

Objects are stored in the heap.

# Fields (Instance Variables)

```java
class Student{

    String name;
    int age;
}
```

These variables belong to every object.

Example

```java
Student s1 = new Student();
Student s2 = new Student();

s1.name = "Ram";
s2.name = "Shyam";
```

Each object has its own copy.

---

# Methods

Methods define the behavior of objects.

```java
class Student{

    String name;

    void study(){

        System.out.println(name + " is studying");
    }
}
```

Using it

```java
Student s = new Student();

s.name = "Rahul";

s.study();
```

Output

```
Rahul is studying
```

# this Keyword

`this` refers to the current object.

Without `this`

```java
Student(String name){

    name=name;
}
```

Nothing changes because the parameter shadows the field.

Correct

```java
Student(String name){

    this.name=name;
}
```

# Object Reference

```java
Student s1 = new Student();

Student s2 = s1;
```

Both references point to the same object.

```
s1 ------
          \
           \
            Object
           name=Rahul
          /
         /
s2 -----
```

Changing one affects the other.

```java
s1.name="Rahul";

System.out.println(s2.name);
```

Output

```
Rahul
```

# Passing Object to Method

```java
class Student{

    String name;
}

    }

    public static void main(String args[]){

        Student s=new Student();

        print(s);
    }
}
```

Output

```
Rahul
```

# Returning Object

```java
class Student{

    String name;
}

public class Main{

    static Student create(){

        Student s=new Student();

        s.name="Rahul";

        return s;
    }

    public static void main(String args[]){

        Student s=create();

        System.out.println(s.name);
    }
}
```

Output

```
Rahul
```

# Static Members

A `static` field belongs to the class, not individual objects.

```java
class Student{

    static String college="ABC College";

    String name;
}
```

```java
Student s1=new Student();
Student s2=new Student();

s1.name="Rahul";
s2.name="Priya";

System.out.println(Student.college);
```

Output

```
ABC College
```

Only one copy of `college` exists.

---

# Instance vs Static

| Instance            | Static                  |
| ------------------- | ----------------------- |
| Belongs to object   | Belongs to class        |
| Many copies         | One copy                |
| Access using object | Access using class name |

# Real-Life Example: Bank Account

```java
class BankAccount {

    String accountHolder;
    int balance;

    BankAccount(String holder, int amount) {
        accountHolder = holder;
        balance = amount;
    }

    void deposit(int amount) {
        balance += amount;
    }

    void withdraw(int amount) {
        balance -= amount;
    }

    void display() {
        System.out.println("Holder: " + accountHolder);
        System.out.println("Balance: " + balance);
    }
}

public class Main {

    public static void main(String[] args) {

        BankAccount a1 = new BankAccount("Rahul", 5000);

        a1.deposit(2000);
        a1.withdraw(1000);

        a1.display();
    }
}
```

Output

```
Holder: Rahul
Balance: 6000
```

# Question 5: Circle Area and Circumference

### Question

Create a `Circle` class.

* Variable:

  * `radius`
* Use a constructor.

  * Area
  * Circumference

### Answer

```java
class Circle {

    double radius;

    Circle(double radius) {

        this.radius = radius;
    }

    void area() {

        System.out.println("Area = " + (3.14 * radius * radius));
    }

    void circumference() {

        System.out.println("Circumference = " + (2 * 3.14 * radius));
    }
}

public class Main {

    public static void main(String[] args) {

        Circle c = new Circle(7);

        c.area();
        c.circumference();
    }
}
```
