## Encapsulation in Java (Practical Explanation)

**Encapsulation** means:

* Hiding the internal data of a class
* Allowing controlled access through methods

In practice:

* Variables are usually made `private`
* Access is provided using **getters** and **setters**

---

# 1. Why Encapsulation?

Without encapsulation:

```java
class Student {
    public int age;
}
```

Anyone can directly change `age`:

```java
Student s = new Student();
s.age = -100;   // invalid
```

This is unsafe.

---

# 2. Using Encapsulation Properly

```java
class Student {

    // private data members
    private String name;
    private int age;

    // getter methods
    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }

    // setter methods
    public void setName(String n) {
        name = n;
    }

    public void setAge(int a) {

        // validation
        if(a > 0) {
            age = a;
        }
    }
}
```

---

# 3. Using the Class

```java
public class Main {

    public static void main(String[] args) {

        Student s = new Student();

        s.setName("Rahul");
        s.setAge(21);

        System.out.println(s.getName());
        System.out.println(s.getAge());
    }
}
```

### Output

```text
Rahul
21
```

# 4. Access Modifiers in Java

| Modifier    | Same Class | Same Package | Subclass | Other Package |
| ----------- | ---------- | ------------ | -------- | ------------- |
| `private`   | YES        | NO           | NO       | NO            |
| default     | YES        | YES          | NO       | NO            |
| `protected` | YES        | YES          | YES      | NO            |
| `public`    | YES        | YES          | YES      | YES           |

# 5. Practical Example with Validation

```java
class BankAccount {

    private double balance;

    public void deposit(double amount) {

        if(amount > 0) {
            balance += amount;
        }
    }

    public double getBalance() {
        return balance;
    }
}
```

Usage:

```java
BankAccount b = new BankAccount();

b.deposit(5000);

System.out.println(b.getBalance());
```

This prevents:

```java
b.balance = -100000; // NOT allowed
```

because `balance` is `private`.


# 1. Employee (Salary Validation) ⭐

**Concepts:**

* Private variables
* Getters & setters
* Validation

```java
class Employee {

    private String name;
```

```text
Rahul
```

# 3. Bank Account ⭐⭐

**Logic**

* Deposit only if amount > 0
* Withdraw only if balance is sufficient

```java
class BankAccount {

    private double balance;

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public void withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
        }
    }

    public double getBalance() {
        return balance;
    }
}

public class Main {

    public static void main(String[] args) {

        BankAccount b = new BankAccount();

        b.deposit(5000);

        b.withdraw(1200);

        System.out.println(b.getBalance());
    }
}
```

**Output**

```text
3800.0
```

# 5. ATM (Most Important) ⭐⭐⭐

**Logic**

* Store PIN privately.
* Deposit only positive amounts.
* Withdraw only if:

  * PIN is correct.
  * Balance is sufficient.

```java
class ATM {

    private int pin;
    private double balance;

    public void setPin(int pin) {
        this.pin = pin;
    }

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public void withdraw(double amount, int enteredPin) {

        if (enteredPin == pin && amount <= balance) {
            balance -= amount;
            System.out.println("Withdrawal Successful");
        } else {
            System.out.println("Transaction Failed");
        }
    }

    public double getBalance() {
        return balance;
    }
}

public class Main {

    public static void main(String[] args) {

        ATM a = new ATM();

        a.setPin(1234);

        a.deposit(5000);

        a.withdraw(1000, 1234);

        System.out.println(a.getBalance());
    }
}
```

**Output**

```text
Withdrawal Successful
4000.0
```

## Pattern to Remember (Works for Almost Every Encapsulation Question)

```java
class ClassName {

    private DataType variable;

    public void setVariable(DataType variable) {
        // validation if needed
        this.variable = variable;
    }

    public DataType getVariable() {
        return variable;
    }
}
```
